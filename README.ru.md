# Corporate Settlement Service

> [🇬🇧 English](README.md) | 🇷🇺 Русский

REST-сервис для управления корпоративными расчётными счетами и экземплярами продуктов.

## Возможности

- **CSA (Corporate Settlement Account)** — создание продуктового регистра (расчётного счёта) для существующего экземпляра продукта
- **CSI (Corporate Settlement Instance)** — создание нового экземпляра продукта с автоматическим открытием регистров либо добавление дополнительных соглашений к существующему экземпляру
- Структурированные коды ошибок при отсутствии обязательных полей или ненайденных ресурсах
- PostgreSQL в продуктиве, H2 для тестов
- Контроль покрытия тестами через JaCoCo

### Резервирование счетов

Свободный счёт выбирается через `SELECT … FOR UPDATE`, затем в той же транзакции
получает `bussy=true` и связывается с новым регистром. Параллельные запросы ждут
освобождения строки и повторно проверяют занятость. При исчерпании пула возвращается
404. Откат внешней транзакции CSI отменяет и резервирование счёта.

Счета, уже указанные в регистрах, исключаются из выдачи даже при устаревшем флаге
занятости. Существующие повторные назначения требуют отдельной сверки данных;
исправление не переписывает старые регистры.

Все тесты запускаются командой `mvn test`. Регрессионные проверки резервирования
на отдельной временной PostgreSQL запускаются так:

```bash
docker compose -f compose.reservation-tests.yml run --rm test
docker compose -f compose.reservation-tests.yml down
```

Проверяются три одновременных назначения, исчерпание пула, откат транзакции и
устаревшие флаги. База не публикует порты и использует временное хранилище.
Не подключайте тесты к существующей базе — SQL-инициализация приложения
пересоздаёт таблицы.

## Защита от конкурентных дублей

Уникальные ограничения базы защищают номер договора, пару `(product_id, type)`
регистра и номер дополнительного соглашения. При трёх одинаковых параллельных
HTTP-запросах один проходит, два получают понятную ошибку 400. Откат не оставляет
лишних продуктов, регистров и занятых счетов. Другие ошибки целостности возвращают
500 без SQL и внутренних деталей в ответе.

В новых тестовых базах ограничения создаёт `schema.sql`. Для существующей
PostgreSQL сделайте резервную копию и в окно обслуживания примените
`ops/sql/2026-11-14-unique-business-keys.sql` через
`psql -v ON_ERROR_STOP=1 -f ...`. Скрипт блокирует затронутые таблицы, останавливается
при исторических дублях и допускает повторное применение. Сначала сверяйте
дубли, затем повторяйте обновление. Пересоздающий таблицы инициализатор приложения
не предназначен для обновления существующей базы.

Временный PostgreSQL runner также выполняет `ConcurrentCreationTests` с
`-Dsettlement.postgresConcurrency=true`: проверяет одинаковые параллельные запросы
договоров, регистров и соглашений, один успех, две ошибки дубля и итоговое состояние
таблиц. Сервисы и репозитории не подменяются. Эти PostgreSQL-проверки пропускаются
в обычном H2-прогоне.

## Технологии

| Слой | Технология |
|---|---|
| Язык | Java 11 |
| Фреймворк | Spring Boot 2.7.9 |
| Persistence | Spring Data JPA / Hibernate |
| База данных | PostgreSQL (продуктив), H2 (тесты) |
| Сборка | Maven |
| Утилиты | Lombok |
| Контейнеризация | Docker / Docker Compose |

## Требования

- Java 11+
- Maven (или используйте встроенный wrapper `./mvnw`)
- Docker и Docker Compose (опционально, для запуска в контейнерах)
- PostgreSQL (при локальном запуске без Docker)

## Установка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd <project-folder>
```

### С Docker Compose

```bash
docker-compose up --build
```

Сервис поднимается на порту `8080`, база данных PostgreSQL — на `6541`.

### Локально

1. Запустить PostgreSQL (или использовать `docker-compose up db`).
2. Убедиться, что в `application.properties` указаны корректные параметры подключения.
3. Запустить сервис:

```bash
./mvnw spring-boot:run -pl service
```

## API

### POST `/corporate-settlement-account/create`

Создаёт продуктовый регистр (счёт) для существующего экземпляра продукта.

**Тело запроса:**

| Поле              | Тип    | Обязательное | Описание                       |
|-------------------|--------|:------------:|---------------------------------|
| `instanceId`      | Long   | ✓            | ИД экземпляра продукта         |
| `registryTypeCode`| String | ✓            | Код типа регистра              |
| `currencyCode`    | String |              | Код валюты                     |
| `branchCode`      | String |              | Код отделения                  |
| `priorityCode`    | String |              | Код приоритета                 |
| `mdmCode`         | String |              | МДМ-код клиента                |
| `accountType`     | String |              | Тип счёта                      |
| `clientCode`      | String |              | Код клиента                    |
| `trainRegion`     | String |              | Регион обучения                |
| `counter`         | String |              | Счётчик                        |
| `salesCode`       | String |              | Код продаж                     |

**Пример ответа:**

```json
{
  "data": {
    "accountId": "42"
  }
}
```

---

### POST `/corporate-settlement-instance/create`

Создаёт новый экземпляр продукта или добавляет дополнительные соглашения к существующему.

**Тело запроса:**

| Поле                       | Тип           | Обязательное | Описание                                                      |
|----------------------------|---------------|:------------:|----------------------------------------------------------------|
| `instanceId`               | Integer       |              | ИД существующего экземпляра (если указан — режим обновления)  |
| `productType`              | String        | ✓            | Тип продукта                                                   |
| `productCode`              | String        | ✓            | Код продукта из каталога                                       |
| `registerType`             | String        | ✓            | Тип регистра                                                   |
| `mdmCode`                  | String        | ✓            | МДМ-код клиента                                                |
| `contractNumber`           | String        | ✓            | Номер договора                                                 |
| `contractDate`             | LocalDateTime | ✓            | Дата договора                                                  |
| `priority`                 | Integer       | ✓            | Приоритет                                                      |
| `contractId`               | Integer       | ✓            | ИД договора                                                    |
| `branchCode`               | String        | ✓            | Код отделения                                                  |
| `isoCurrencyCode`          | String        | ✓            | ISO-код валюты                                                 |
| `urgencyCode`              | String        | ✓            | Код срочности                                                  |
| `interestRatePenalty`      | Float         |              | Процентная ставка пени                                         |
| `thresholdAmount`          | Float         |              | Пороговая сумма                                                |
| `taxPercentageRate`        | Float         |              | Налоговая ставка (%)                                           |
| `instanceArrangementDto`   | Array         |              | Список дополнительных соглашений                               |

**Пример ответа (создание):**

```json
{
  "data": {
    "instanceId": "15"
  },
  "registerId": ["23", "24"],
  "supplementaryAgreementId": null
}
```

**Пример ответа (обновление):**

```json
{
  "data": {
    "instanceId": "15"
  },
  "registerId": null,
  "supplementaryAgreementId": ["7"]
}
```

## Коды ошибок

| HTTP-код | Причина                                                            |
|----------|---------------------------------------------------------------------|
| 400      | Не заполнено обязательное поле, или запись с такими данными уже существует |
| 404      | Не найден тип регистра, пул счетов, или экземпляр продукта         |

## Структура базы данных

| Таблица                          | Описание                                  |
|----------------------------------|---------------------------------------------|
| `tpp_product`                    | Экземпляры продуктов                       |
| `tpp_product_register`           | Продуктовые регистры (счета)               |
| `agreement`                      | Дополнительные соглашения                  |
| `account_pool`                   | Пулы свободных счетов                      |
| `account`                        | Счёта в пулах                              |
| `tpp_ref_product_class`          | Справочник классов продуктов               |
| `tpp_ref_product_register_type`  | Справочник типов регистров                 |
| `tpp_ref_account_type`           | Справочник типов счетов                    |
| `tpp_template_register_balance`  | Шаблоны балансов регистров                 |

## Тесты

```bash
./mvnw test -pl service
```

Тесты используют встроенную базу данных H2 в режиме совместимости с PostgreSQL. Покрытие контролируется JaCoCo (профиль `coverage`):

```bash
./mvnw verify -pl service -P coverage
```
